新增 WCAG 颜色对比度检查器

新增一个明显可见的 COLOR CONTRAST CHECKER，用于在测试站内直接验证文字与背景配色的可读性。访客可以选择两种颜色、交换前景与背景，并实时看到 WCAG 对比度与不同文本等级的通过状态。

  • 实时计算 sRGB 相对亮度与对比度，直接显示精确到两位小数的比例。
  • 分别显示普通文本 AA / AAA、大文本 AA / AAA，以及 UI / 图形 3:1 阈值的通过状态。
  • 提供原生颜色选择器、SWAP 交换按钮和实时文字预览，结果变化通过 aria-live 状态区域同步给辅助技术。
  • 快速导航会动态新增 CONTRAST 入口；组件放置在 Accessibility Preferences 前方，与现有诊断流程保持一致。
  • 支持移动端、高对比度模式与 reduced-motion；没有增加第三方脚本、付费依赖或外部运行时资源。
  • 本轮通过页面已有的本地脚本入口加载新组件，因此 test.html 与 index.html 仍保持同一当前页面 blob，原有功能不被重写。
