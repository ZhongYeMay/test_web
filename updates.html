2026-08-14 21:34:29 UTC+8UPDATE #073

新增评论、点赞、收藏、下载、转发，并按真实 tag 自动分区

播放器新增点赞、收藏、下载、转发与评论操作。点赞、收藏和评论使用当前浏览器 localStorage 保存，并明确标注本地状态；收藏的视频会在首页出现“我的收藏”区域。下载直接请求当前真实视频源，转发优先使用系统 Web Share，并在不支持时回退到复制播放链接。首页分类不再依赖预设“动画/游戏/科技”等静态分区，而是读取 novavideos/videos.json 中每个真实视频的 tags，动态生成顶部 tag 筛选、侧栏 tag 导航和独立 tag 分区；当前页面保持打开时每 60 分钟自动重新读取 manifest 并同步分区。

2026-08-14 21:02:23 UTC+8UPDATE #072

真实视频源加载时新增稳定骨架，避免 DEMO 内容闪现

推荐区在 novavideos/videos.json 尚未返回时不再短暂展示演示卡片，而是显示与正式视频卡片等尺寸的加载骨架，预留缩略图与元数据空间；只有在清单确认为空或读取失败时才进入 DEMO 回退。加载期间同时清空搜索建议的数据源，并在推荐区域使用 aria-busy 标记动态更新状态；减少动态效果偏好开启时关闭骨架动画。

统一键盘焦点可视化与高对比模式支持
