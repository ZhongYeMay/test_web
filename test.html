// QUICK START

TEST FLOW

按这四步走一遍，就能快速检查页面最重要的部署、浏览器与地图功能。

  1. Run diagnostics点击上方 RUN TEST，检查 JavaScript、浏览器与页面环境。
  2. Resize viewport调整窗口宽度，观察指标卡和布局是否能在不同尺寸下正常重排。
  3. Inspect visitor map确认本地 SVG 世界地图可见，并查看当前访问位置与国家级统计加载情况。
  4. Review history打开 Update History，浏览并下载每次修改前保存的历史 HTML。

QUICK SHORTCUTS
